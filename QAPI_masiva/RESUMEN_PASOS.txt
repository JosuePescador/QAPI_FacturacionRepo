❌ ERRORES COMUNES Y SOLUCIONES
────────────────────────────────────────────────────────────────────────────────

  ❌ "java: command not found"
     ✅ Java no está instalado
     ✅ Solución: apt-get install openjdk-17-jdk-headless


  ❌ "Port 8080 already in use"
     ✅ Otro servicio está usando el puerto
     ✅ Solución: java -jar ... --server.port=9090


  ❌ "BUILD FAILURE"
     ✅ Error de compilación
     ✅ Solución: ./mvnw clean (limpia) y reintentar


  ❌ "AWS Exception: Unable to load credentials"
     ✅ Credenciales AWS no configuradas
     ✅ Solución: export AWS_ACCESS_KEY_ID=... (solo si usas SQS)


  ❌ "Connection refused"
     ✅ La app no está corriendo
     ✅ Solución: Verifica que el JAR esté ejecutándose
